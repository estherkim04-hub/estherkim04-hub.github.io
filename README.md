# Jinseo Kim Academic Website

## Fastest deployment with GitHub Pages
1. Create a new public GitHub repository, e.g. `jinseo-kim.github.io` or `academic-homepage`.
2. Upload everything in this folder to the repository root:
   - `index.html`
   - `styles.css`
   - `Jinseo_Kim_CV.pdf`
   - `assets/jinseo_kim.jpg`
3. If the repo is named `YOURUSERNAME.github.io`, the site will be available at:
   `https://YOURUSERNAME.github.io`
4. Otherwise, open GitHub repository → Settings → Pages → Deploy from a branch → `main` / root.
5. Copy the published URL into the SiR application form.

You can edit all text directly in `index.html`.
